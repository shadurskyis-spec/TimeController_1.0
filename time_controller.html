How to use

Change the hours and minutes independently. When a value reaches its limit, it loops back to the beginning (or end when decreasing).

Increase hourH+ H
Decrease hourH− N
Increase minuteM+ M
Decrease minuteM− J
Reset to current timeR

On phones and tablets, tap the H+/H− and M+/M− buttons. On computers, use the letter keys shown above. The ? button opens this tutorial.
